# Totem de Autoatendimento

Totem de check-in e check-out para hotelaria, preparado para integração com TOTVS Hotelaria Guest API, ACR122U NFC, webcam USB, impressora POS 80 mm e terminal de pagamento Gertec PPC930.

> MVP visual e de fluxo com adapters de integração simulados. Não usar em produção sem configurar integrações, segurança e homologações.
